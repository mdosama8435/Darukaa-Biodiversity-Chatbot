# Evaluation Framework

This directory houses the quantitative evaluation datasets, metric definitions, and runner scripts for benchmarking the AI Biodiversity Intelligence Chatbot.

## Evaluation Dimensions
1. **Clarification Accuracy**: Precision and recall in identifying missing environmental variables.
2. **Multi-Variable Reasoning**: Capability to reason across $\ge 3$ interdependent environmental variables (e.g. soil pH, moisture, species richness).
3. **Evidence Grounding Coverage**: Ratio of claims backed by retrieved scientific documents.
4. **Citation Precision**: Verification of scientific sources cited in recommendations.
5. **Context Retention**: Maintaining consistency across multi-turn dialogues.
