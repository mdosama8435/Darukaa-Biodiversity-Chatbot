# Environmental Data Repository

This directory holds structured environmental records, sensor telemetry datasets, and regional ecological profiles.

## Variables Tracked
1. **Soil**: pH, Organic Carbon (SOC), Soil Moisture
2. **Climate**: Temperature, Rainfall
3. **Land**: Land Use, Land Cover
4. **Biodiversity**: Species Richness, Habitat Diversity
5. **Human Impact**: Pollution, Deforestation
6. **Location**: Region, Latitude, Longitude

## Subdirectories
- `raw/`: Unprocessed field surveys, CSVs, GeoJSONs.
- `processed/`: Validated, normalized, and benchmarked environmental snapshots.
