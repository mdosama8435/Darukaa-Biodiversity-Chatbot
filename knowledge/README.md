# Scientific Knowledge Repository

This directory manages scientific literature, ecological benchmarks, and environmental research documents used for Retrieval-Augmented Generation (RAG).

## Structure
- `sources/`: Original raw scientific documents, open-access papers, soil taxonomies, and IUCN guidelines.
- `processed/`: Chunked, sanitized, and structured markdown/JSON texts ready for vector embedding.
- `metadata/`: Document citation metadata (DOI, authors, peer-review status, journal name, year, geographical scope).

## Grounding Principle
All recommendations generated by the chatbot must trace back to verifiable scientific evidence stored and indexed from this repository.
